02

为什么总是三角形？

为 什 么 需 要 它
  • 三点必共面 —— 四个点可能扭成马鞍面，三个点永远平整
  • 永远凸 —— 边界干净，「在内 / 在外」没有歧义
  • 好插值 —— 内部任一点 = 三顶点的加权平均，权重唯一

再华丽的模型，喂给 GPU 之前都会被拆成三角形。还有一个隐藏福利：内外测试和属性插值在三角形上用的是同一套数学 —— 03、04 节揭晓。

03

边函数 · 点在线的哪一侧？

为 什 么 需 要 它

覆盖测试 = 判断「点是否在三条边的同一侧」。我们不需要距离，只需要一把回答「侧」的尺子 —— 2D 叉积。

边 函 数 · EDGE FUNCTION EAB(P) = (B − A) × (P − A) = (Bx−Ax)(Py−Ay) − (By−Ay)(Px−Ax)
数值 = △ABP 的有向面积 × 2 ｜ 符号 = 侧：E > 0 一侧，E < 0 另一侧，E = 0 正好在线上
覆 盖 规 则 · COVERAGE RULE P 在三角形内　⟺　EAB(P)、EBC(P)、ECA(P) 三者同号
顶点环绕方向反过来也没关系 —— 三个值一起变号，规则照样成立。

一个像素三次叉积，全屏百万像素同时提问 —— 这正是 GPU 并行架构的本职工作。

04

重心坐标 · 属性如何摊到内部？

为 什 么 需 要 它

颜色、UV、深度都记在顶点上，着色却发生在像素上 —— 需要一张从顶点到内部的「分配地图」。

重 心 坐 标 · BARYCENTRIC COORDINATES λ0 = A0/A　　λ1 = A1/A　　λ2 = A2/A　　（Ai 是 P 对面那块小三角形的面积，A 是总面积）
λ0 + λ1 + λ2 = 1　　·　　P = λ0V0 + λ1V1 + λ2V2　　·　　attr(P) = Σ λi·attri
✦ 关 键 洞 察 面积 A0 × 2 正是 EBC(P) —— 覆盖测试已经算过的数！所以 λi = Ei ÷ (E0+E1+E2)。
一次叉积，既定内外、又出权重。零额外成本 —— 这就是 GPU 对这套算法死心塌地的原因。
05

透视校正 · 屏幕上的「线性」是假的

为 什 么 需 要 它

插值在屏幕空间做，属性却属于三维世界。投影近大远小 —— 三维里等距的东西，屏幕上必然不等距。直接在屏幕上均匀插值，贴图就会扭曲。

透 视 校 正 · PERSPECTIVE-CORRECT INTERPOLATION 屏幕上真正线性变化的是 1/w 和 attr/w（w = 顶点投影后的深度）：
attr(P) = Σ λi · attri/wiΣ λi / wi 　　先 ÷w 再插值，插完再除回来 —— GPU 对每个属性自动做这一步。

跳过它的代价：贴图在三角形接缝处「拧麻花」—— PS1 时代的经典事故。

06

硬件为什么爱它？

为 什 么 是 这 种 算 法
增 量 计 算 · INCREMENTAL E(x,y) = a·x + b·y + c　⟹　E(x+1, y) = E(x,y) + a　　E(x, y+1) = E(x,y) + b
边函数是关于像素坐标的一次函数 —— 走到相邻像素只差一次加法。
  • 无分支、无跳转 —— 同一套乘加，GPU 以 tile / quad 为单位让几万个像素同时作答
  • 形状简单 —— 简单到可以直接焊进硅片（固定功能单元），快而且省电

好算法的标准不只是「算得巧」，更是长得就像硬件 —— 这是光栅化统治实时渲染三十年的根本原因。

07

填充规则 · 边界像素归谁？

为 什 么 需 要 它

两个三角形共享一条边：边上的像素若画两次，半透明混合就错；若都不画，模型表面就裂缝。

OpenGL / Direct3D 的约定叫 top-left rule：落在边上的像素，仅当那条边是本三角形的「上边或左边」时才归它 —— 于是每个边界像素恰好归一个三角形：无缝、无重叠。规则本身不重要，重要的是必须有规则。

08

锯齿 · 本质是采样率不够

为 什 么 会 锯 齿

每像素只采 1 次样，几何边缘的变化却「无限快」—— 欠采样 ⇒ 走样（这是 Nyquist 采样定理的直觉版）。

MSAA：每像素 N 个采样点估计覆盖率，但着色仍每像素一次 —— 只多测覆盖、不多算颜色，所以便宜。「一个像素 4 个采样位置」正是为此而存在。

09

光栅化实验场

拖动三个顶点，看哪些像素被盖章；调密网格，看锯齿悄悄消失；打开 MSAA，看边缘按覆盖率过渡。

四条公式带走

EAB(P) = (B−A) × (P−A)覆盖测试 · 三个边函数值同号 ⇒ 在三角形内
λi = Ei / (E0+E1+E2)插值权重 · 覆盖测试顺手产出，零额外成本
attr(P) = Σ λi·attri属性插值 · 颜色 / UV / 深度都按它摊到内部
attr = Σ(λi·attri/wi) ÷ Σ(λi/wi)透视校正 · 屏幕上真正线性的是 1/w
覆盖测试决定哪些像素上岗 → 属性插值给它们发装备 → 打包成片元交给下游。
光栅化，就是连续世界到离散世界的翻译官。
