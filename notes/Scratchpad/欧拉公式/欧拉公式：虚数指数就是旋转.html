欧拉公式：虚数指数就是旋转

\(e^{i\theta} = \cos\theta + i\sin\theta\) —— 指数函数的自变量乘上 \(i\)，"增长"就被扭转成了"旋转"。

§ 1

虚数：不是"想象"，是"转身"

方程 \(x^2 + 1 = 0\) 在实数范围内无解——任何实数的平方都不可能是负数。数学家的回应很干脆：定义一个新数，规定

$$i^2 = -1$$

然后继续做代数，看看会发生什么。

先不急着纠结"\(i\) 到底是什么"。本文会看到：它不必被理解为一个虚无缥缈的"想象中的数"——它其实是一个动作：旋转 90°。这是全文埋下的第一个伏笔。

§ 2

复数：一个数 = 平面上的一个点

把实数和 \(i\) 混在一起做加法，就得到复数。每个复数有两种写法，对应平面上一个点的两种坐标：

直角坐标（代数形式）：

$$z = a + bi$$

极坐标（三角形式）：

$$z = \rho(\cos\theta + i\sin\theta),\qquad \rho = \sqrt{a^2+b^2},\ \ \tan\theta = \frac{b}{a}$$

\(\rho\) 叫模——点到原点的距离；\(\theta\) 叫辐角——与实轴正方向的夹角。一个是"横多少、竖多少"，一个是"多远、朝哪"。

§ 3

复数乘法：模相乘，角相加

两个三角形式的复数相乘，展开后三角恒等式会自动把角度"合并"：

$$ \begin{aligned} z_1 z_2 &= \rho_1(\cos\theta_1 + i\sin\theta_1)\cdot \rho_2(\cos\theta_2 + i\sin\theta_2)\\[2pt] &= \rho_1\rho_2\big[(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) + i(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)\big]\\[2pt] &= \rho_1\rho_2\big[\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)\big] \end{aligned} $$

一句话点睛：乘以 \(\rho_2(\cos\theta_2 + i\sin\theta_2)\) 的几何效果 = 长度变为 \(\rho_2\) 倍，再旋转 \(\theta_2\) 角。复数乘法的本质，就是"缩放 + 旋转"。

§ 4

乘 \(i\) = 旋转 90°：从特例到矩阵

把乘法公式用到 \(i\) 身上。注意 \(i = 0 + 1\cdot i\)，即模为 1、辐角为 \(\pi/2\)：

$$i = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2}$$

所以"乘 \(i\)"不缩放、只旋转——恰好逆时针转 90°。连续乘两次，就是转 180°：

$$z \xrightarrow{\ \times i\ } iz \xrightarrow{\ \times i\ } i^2 z = -z$$

这正是 \(i^2 = -1\) 的几何含义："旋转 90° 做两次 = 掉头反向"。代数定义与几何动作，在此合流。

与旋转矩阵的严格对应

这不只是比喻，而是严格的同构。每个复数可以唯一对应一个实矩阵：

$$a + bi \ \longleftrightarrow\ \begin{pmatrix} a & -b \\ b & a \end{pmatrix}$$

复数的加法和乘法，恰好对应矩阵的加法和乘法。在此对应下：

$$i \ \longleftrightarrow\ J = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix},\qquad J^2 = -I$$

\(J\) 正是平面旋转 90° 的矩阵。一句话：\(i\) 是"数"版本的旋转 90°，\(J\) 是"矩阵"版本的旋转 90°——同一个动作，两套语言。

§ 5

\(e^x\) 的启示：什么样的运动会"导数等于自身"？

实数世界里，指数函数有一条著名的指纹：

$$\frac{d}{dx}e^x = e^x$$

变化率 = 当前值。更一般地，满足 \(f' = kf\) 的函数只有 \(Ce^{kx}\) 这一族——这是指数函数独有的签名。

现在把这个问题搬到复平面，问一个几何问题：

质点在复平面上运动，若它的速度始终等于当前位置向量旋转 90°（速度 ⊥ 位置，速率 = 到原点的距离），轨迹是什么？

速度永远垂直于位置向量：它只改变方向，不改变到原点的距离。答案只能是——以原点为中心的匀速圆周运动。

用函数写出来。取单位圆上的点 \(f(\theta) = \cos\theta + i\sin\theta\)，直接求导：

$$f'(\theta) = -\sin\theta + i\cos\theta = i\,(\cos\theta + i\sin\theta) = i\,f(\theta),\qquad f(0) = 1$$

乘 \(i\) 正是"旋转 90°"，所以这个导数关系说的就是：速度 = 位置旋转 90°。圆周运动确实满足这个方程。

而按指数函数的指纹：满足 \(f'(\theta) = i\,f(\theta)\) 且 \(f(0) = 1\) 的函数，只能是 \(f(\theta) = e^{i\theta}\)。

同一个微分方程、同一个初值，解唯一——所以它们必须是同一个函数。

§ 6

欧拉公式

$$e^{i\theta} = \cos\theta + i\sin\theta$$

三条精确化总结：

  • 纯虚数指数 = 纯旋转：\(\left|e^{i\theta}\right| = 1\)，\(\theta\) 就是转过的角度。
  • 一般复指数 = 缩放 × 旋转：\(e^{a+bi} = e^a\cdot e^{bi} = e^a(\cos b + i\sin b)\)。实部管缩放，虚部管旋转。
  • 特例 \(e^{i\pi} + 1 = 0\)：旋转半圈，恰好到达 \(-1\)——五个最重要的常数（\(e, i, \pi, 1, 0\)）被一次旋转串起。

把自变量乘上 \(i\)，指数函数的"增长方向"被扭转 90°——于是增长变成了旋转。这就是欧拉公式最核心的一句话。
