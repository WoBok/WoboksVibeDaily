Hierarchy

从芯片到一个执行核心

GB202 的并行规模来自规则复制：GPC 包含 TPC，TPC 包含两个 SM，而每个 SM 再分成四个执行分区。

1 × GPU

完整 GB202

统一连接调度、媒体、L2 与外部 GDDR7 内存系统。

12 × GPC

图形处理集群

每个 GPC 有 1 个 Raster Engine、8 个 TPC、16 个 SM 和 16 个 ROP。

8 × TPC

纹理处理集群

每个 TPC 有 1 个 PolyMorph Engine 与 2 个 SM。

2 × SM

流式多处理器

线程束调度、通用计算、AI 矩阵计算、光追与片上存储的基本并行单元。

12 × 8 × 2 = 192 SM
192 × 128 = 24,576 CUDA
192 × 4 = 768 Tensor
192 × 1 = 192 RT

Work flow

工作如何穿过 GB202

图形、通用计算和 AI 会共享许多前端与存储资源，但在 SM 内分流到适合自身数学类型的执行单元。

1CPU / PCIe 5.0CPU 提交命令、资源地址与同步；PCIe 是主机到 GPU 的入口。
2GigaThread / AMP全局工作分配与 AI/图形负载协同，选择要运行的线程块与任务。
3GPC / TPC按图形管线和局部性把工作分到 Raster、PolyMorph 与两个 SM。
4Warp Scheduler从可运行 warp 中选择一个；Dispatch Unit 把 32 个线程的指令发往执行管线。
5CUDA / Tensor / RT标量/向量数值、矩阵乘加和光线-几何求交分别进入专用单元。
6L1 / Shared / L2先利用低延迟片上存储；未命中或跨 SM 共享的数据继续访问统一 L2。
7GDDR7 / ROP内存控制器访问显存；图形结果经 ROP 做深度、混合与最终像素写回。

Module guide

模块详解与相互关系

下面按“全芯片 - GPC/TPC - SM - 存储与输出”解释图中的主要方块。

全芯片

GigaThread Engine

GPU 的全局线程调度前端。它接收命令，将线程块/图形工作分派到 GPC 与 SM，并参与上下文切换。它决定“工作去哪里”，而 SM 内的 Warp Scheduler 决定“这一拍发哪条 warp 指令”。

全芯片

AI Management Processor (AMP)

用于协调多个 AI 模型与图形负载共享 GPU。它位于高层调度侧，不等同于 Tensor Core；AMP 管“任务编排”，Tensor Core 管“矩阵运算”。

全芯片

L2 Cache

所有 GPC/SM 都能访问的片上共享缓存，也是显存前的最后一级缓存。它降低 GDDR7 往返、承载跨 SM 数据共享，并显著影响光追与复杂工作集的性能。

GPC

Graphics Processing Cluster

高级图形并行域。一个完整 GPC 包含 Raster Engine、8 个 TPC、16 个 SM 与两组 ROP 分区。完整 GB202 复制 12 份 GPC，构成主要计算阵列。

GPC

Raster Engine

把经过几何处理的图元转换为片段/像素覆盖，完成裁剪、视口和光栅化等阶段，并把后续着色工作送入 SM。它是传统图形管线从“几何”走向“像素”的关键桥梁。

GPC

ROP

Raster Operations Pipeline 负责最终像素阶段，如深度/模板测试、颜色混合、抗锯齿相关操作和帧缓冲写入。每个完整 GPC 有 16 个 ROP，分成 2 个各含 8 个单元的分区。

TPC

Texture Processing Cluster

位于 GPC 和 SM 之间的组织层级。每个 TPC 含一个 PolyMorph Engine 和两个 SM，使几何处理、纹理/着色资源以可复制的小组形式扩展。

TPC

PolyMorph Engine

处理顶点获取、曲面细分、属性设置、视口变换等几何前端工作。它与 TPC 内两个 SM 协作，让可编程着色阶段和固定功能几何阶段保持数据局部性。

SM

Streaming Multiprocessor

GPU 最核心的可编程执行单元。一个 GB202 SM 包含 128 个 CUDA Core、4 个第五代 Tensor Core、1 个第四代 RT Core、4 个纹理单元、256 KB Register File 和 128 KB 可配置 L1/Shared Memory。

SM 调度

Warp 与 Warp Scheduler

CUDA 线程按 32 个组成一个 warp，并以同一条指令协同执行。每个 SM 有 4 个调度分区；每个分区的 Warp Scheduler 从就绪 warp 中选择下一条指令，用大量并发 warp 隐藏访存延迟。

SM 调度

Dispatch Unit

把 Warp Scheduler 选中的指令送入正确的执行管线。图中标注 32 thread/clk，表示一次发射覆盖一个 32 线程 warp；它是调度决策与 CUDA/Tensor/LD-ST/SFU 等执行资源之间的出口。

SM 前端

L0 Instruction Cache

靠近每个调度分区的指令缓存，提供当前 warp 的机器指令，降低前端取指等待。它缓存的是“要执行的指令”，不是 CUDA 核心读写的普通数据。

SM 存储

Register File

线程私有寄存器的高速片上存储。每个 SM 分区标注 16,384 × 32-bit，四个分区合计 256 KB。寄存器使用量会影响同一 SM 能同时驻留多少 warp，进而影响 occupancy。

SM 执行

CUDA Core / FP32-INT32

执行通用标量/向量算术与逻辑指令，是着色器、物理、图像处理和常规 CUDA 内核的基础。Blackwell 将许多 INT32 能力与 FP32 路径完全统一；同一核心在一个周期中只能选择 FP32 或 INT32。

SM 执行

5th Generation Tensor Core

专门做矩阵乘加，面向 AI 训练/推理和神经渲染。RTX Blackwell 支持 FP16、BF16、TF32、INT8、FP8，并新增 FP4/FP6；每个 SM 四个 Tensor Core，分别贴近四个调度分区。

SM 执行

4th Generation RT Core

卸载 BVH 遍历和光线-几何求交。GB202 版本包含 Box Intersection、Triangle Cluster Intersection、Linear Swept Spheres、Opacity Micromap 与 Triangle Cluster Compression 等固定功能引擎。

SM 执行

LD/ST Unit

Load/Store Unit 计算地址并在寄存器、L1/共享内存、L2 和显存之间搬运数据。CUDA Core 做算术，LD/ST 负责数据进出；两者重叠得越好，越能隐藏内存延迟。

SM 执行

SFU

Special Function Unit 加速倒数、平方根、三角/超越函数等特殊数学运算。它处理不适合普通 FP32 加法/乘法流水线的函数，是 CUDA 执行资源的补充。

SM 存储

128 KB L1 / Shared Memory

同一片片上存储可在硬件管理的 L1 数据缓存与程序员显式管理的 Shared Memory 之间配置。L1 利于自动复用，Shared Memory 利于线程块内协作与可预测的数据分块。

SM 纹理

Texture Unit

执行纹理地址处理、采样和过滤，返回 texel 给着色器。每个 SM 四个、完整芯片 768 个。它通过缓存层级取数，并把过滤结果交回 CUDA/Tensor 相关着色工作。

内存

Memory Controller / GDDR7

完整 GB202 用 16 个 32-bit 控制器形成 512-bit 接口。请求通常先经过 L1 和 L2，只有缺失或写回才到 GDDR7；控制器负责命令调度、通道访问与数据传输。

媒体

NVENC / NVDEC / Optical Flow

独立固定功能模块分别处理视频编码、视频解码和光流估计。它们不属于 SM，因此视频任务可在较少占用 CUDA 执行资源的情况下运行，并能与图形/AI 工作并发。

Relationship map

容易混淆的关系

概念它不是什么正确关系
SM 与 CUDA CoreSM 不是一个“核心”SM 是完整的多处理器；CUDA Core 只是 SM 内执行 FP32/INT32 等指令的一类算术单元。
Warp Scheduler 与 CUDA Core调度器不做算术Scheduler 选择 warp，Dispatch 发射指令，CUDA/Tensor/LD-ST/SFU 等单元真正执行。
Tensor Core 与 CUDA CoreTensor Core 不是更多的 CUDA Core两者是并列的执行管线：CUDA 适合通用指令，Tensor 适合高吞吐矩阵乘加。
RT Core 与 Raster EngineRT Core 不负责普通光栅化RT Core 位于 SM 侧并加速光线求交；Raster Engine 位于 GPC 侧并把三角形转成像素覆盖。
L1 与 Shared Memory不是两块完全独立的容量GB202 SM 中二者共享 128 KB 可配置片上存储，分别提供硬件缓存和软件管理两种使用方式。
L2 与 GDDR7L2 不是显存容量L2 是芯片内共享缓存；GDDR7 是芯片外大容量显存。L2 未命中才需要访问外部内存。
完整 GB202 与 RTX 5090不能直接把完整芯片数量当作零售卡规格完整设计有 192 SM；RTX 5090 启用 170 SM。网页总图展示前者，并单独标注后者。
