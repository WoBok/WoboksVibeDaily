Quick glossary

核心术语速查

01 · 全局调度

GigaThread Engine

把线程块和图形任务分配到可用的 GPC 与 SM。

02 · 固定功能

NVENC

NVIDIA 的视频编码器，无需依赖 CUDA Core 完成压缩。

03 · 图形层级

GPC

GPU 的大型处理集群，内部包含 Raster Engine、ROP、TPC 和 SM。

04 · GPC

Raster Engine

把三角形等图元转换为屏幕上的像素覆盖范围。

05 · GPC

ROP

处理深度、模板与颜色混合，并把最终像素写入帧缓冲。

06 · 图形层级

TPC

GPC 内的小型处理集群，包含几何前端和两个 SM。

07 · 图形层级

SM

GPU 的主要可编程执行单元，负责线程调度、计算与片上存储。

08 · SM 取指

L1 Instruction Cache

SM 共享的一级指令缓存，为各调度分区提供程序指令。

09 · SM 取指

L0 Instruction Cache

最靠近调度器的小型缓存，快速供应当前 warp 的指令。

10 · SM 调度

Warp Scheduler

从已就绪的 warp 中选择下一条要执行的指令。

11 · SM 调度

Dispatch Unit

把调度器选中的指令送到对应执行管线。

12 · SM 计算

CUDA Core

执行通用浮点、整数和逻辑运算。

13 · SM 计算

FP64 Core

执行双精度浮点运算，GB202 中主要用于程序兼容。

14 · SM 计算

Tensor Core

执行高吞吐矩阵运算，主要服务 AI 与神经渲染。

15 · SM 光追

RT Core

加速光线遍历以及光线与几何体求交。

16 · SM 纹理

Texture Unit

读取纹理、计算纹理坐标并完成采样与过滤。

17 · SM 访存

LD/ST

Load/Store 单元，负责在寄存器、缓存和显存之间读写数据。

18 · SM 计算

SFU

处理平方根、倒数和三角函数等特殊运算。

19 · SM 存储

Register File

保存线程正在使用的数据，是最贴近计算单元的高速存储。

20 · SM 存储

L1/Shared Memory

可作为自动缓存，也可由同一线程块中的线程显式共享。

21 · 全芯片存储

L2 Cache

所有 SM 共享的末级缓存，位于芯片与外部显存之间。

22 · 显存接口

显存控制器

调度显存读写；16 个 32-bit 控制器共同组成 512-bit 接口。

23 · 显存接口

显存总线

GPU 与显存之间的数据通道，位宽决定每次可并行传输的数据量。

24 · 芯片规模

晶体管

构成逻辑与存储电路的基本开关，数量反映芯片集成规模。
