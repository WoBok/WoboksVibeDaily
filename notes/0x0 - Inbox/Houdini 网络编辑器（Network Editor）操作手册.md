## 0. 概述

### 定位

- Network Editor 是 Houdini 中编辑**节点网络**的面板，快捷键配置里的内部名称是 `wsheet`（worksheet）。
- 在任意面板中按 `Alt+2` 可以把它切换为网络编辑器。
- 一个网络编辑器同一时间只显示**一个网络**，也就是某个节点的内部。例如 `/obj` 层显示的是对象，进入 Geometry 对象后显示的是 SOP 节点。

### 界面组成

| 区域 | 内容 |
|---|---|
| 路径栏（顶部） | 当前网络的路径；`Ctrl+L` 可以改为文本输入 |
| 菜单栏 | Add / Edit / Go / View / Tools / Layout / Labs / Help |
| 网络类型标签（右上角） | 当前网络的类型，如 SOP 网络显示 Geometry |
| 画布 | 节点、连线、中转点（dot）、网络框（network box）、便签（sticky note） |

### 基本元素

| 元素 | 说明 |
|---|---|
| 节点 | 一个操作。上方是输入接口，下方是输出接口 |
| 连线 | 从上游节点的输出接到下游节点的输入，数据沿连线向下游流动 |
| 标志（flag） | 节点两侧的开关，控制节点状态，比如哪个节点作为输出显示、是否旁通 |
| 中转点（dot） | 连线上的拐点，用来整理走线 |
| 网络框 / 便签 | 只起组织和注释作用，不影响计算 |

### 标志键

按键固定不变，但对应的标志随网络类型变化：

| 键 | SOP（几何体网络内） | OBJ（`/obj` 层） |
|---|---|---|
| `R` | Display 显示标志 | Display 显示标志 |
| `T` | Render 渲染标志 | — |
| `E` | Template 模板标志 | Selectable 可选标志 |
| `W` | Selectable Template 可选模板标志 | — |
| `Q` / `B` | Bypass 旁通标志（所有网络通用） | 同左 |

> 标志键有两种用法：**选中节点后按一下**，或者**按住键再点击节点**。

## 2. 中频操作

### 连线

| 操作 | 按键 / 鼠标 |
|---|---|
| 剪断连线 | 按住 `Y`，拖过连线 |
| 连续串接多个节点 | 按住 `J`，依次拖过节点 |
| 在接口前插入新节点 | 在接口上按 `RMB` |
| 从接口分支出新节点 | 在接口上按 `MMB` |
| Choose Connection** 菜单 | 在节点上按 `Alt+LMB` |
| 在连线上加中转点 | 在连线上按 `Alt+LMB` |
| 拉线过程中顺手加中转点 | 拉线时按 `Alt+LMB`（`Ctrl+Alt+LMB` 直接为固定状态） |
| 把经过的连线收拢到一个中转点 | 按住 `Alt` 拖动中转点 |
| 切换中转点的固定状态（见下方说明） | 在中转点上按 `Alt+LMB` |
| 断开节点的所有连线 | 拖着节点晃动 |
| 旋转输入顺序 | `Shift+R` |

> **中转点的固定（pin）**：固定与否都不影响拖动，区别在于连线断开后这个点还在不在。
> - **未固定**：进入或离开它的连线全部删除后，这个点会被**自动删除**。它只用来整理走线。
> - **固定**：连线全部断开后仍然**保留**。可以把它当作预留的接头，之后再接线。

> **`X`（Visualize Output）只在 VOP 网络里有用**，比如 Attribute VOP 或材质网络内部。用法是按住 `X` 点击某个 VOP 输出接口，把 Visualize VOP 节点接上去查看这个输出；再按住 `X` 点击别的接口，它就移过去。在 SOP、OBJ 网络里按 `X` 没有反应。

### 选择与复制（高级组合）

| 操作 | 鼠标 |
|---|---|
| 选中节点及其所有上游 | `Alt+Shift+LMB` |
| 选中节点及其所有下游 | `Alt+Ctrl+LMB` |
| 选中节点及其上下游 | `Alt+Shift+Ctrl+LMB` |
| 连同上游一起移动 | 拖动 `Shift+LMB` |
| 连同下游一起移动 | 拖动 `Ctrl+LMB` |
| 拖出副本（含上游 / 含下游） | 拖动 `Alt+Shift+LMB` / `Alt+Ctrl+LMB` |
| 拖出引用副本 | 拖动 `Alt+Ctrl+Shift+LMB` |
| 全选 | `Ctrl+A` |

### 布局

| 操作 | 按键 |
|---|---|
| 整理选中节点 | `L` |
| 整理全部节点 | `Shift+L` |
| 拖动整理（向上/左整理上游，向下/右整理下游） | 按住 `A` 拖动节点 |
| 对齐到某个节点 | 选中节点后按住 `Shift+A`，拖动目标节点 |
| 均匀分布 | 选中节点后按住 `Alt+A` 拖动 |

### 查找与跳转

| 操作 | 按键 |
|---|---|
| 在当前网络查找节点 | `/` |
| 按名称或路径快速跳转 | `Shift+/`（即 `?`） |
| 下一个 / 上一个匹配 | `Ctrl+G`（或 `>`）/ `Ctrl+Shift+G`（或 `<`） |
| 选中上游节点 / 下游节点 | `PageUp` / `PageDown` |
| 选中前一个 / 后一个同级节点 | `Shift+PageUp`（或 `,`）/ `Shift+PageDown`（或 `.`） |
| 回到上一个视图 | `` ` ``（反引号） |
| 保存视图书签 1–5 | `Ctrl+1` … `Ctrl+5` |
| 跳到视图书签 1–5 | `1` … `5` |

## 4. 面板通用键

| 操作 | 按键 |
|---|---|
| 当前面板最大化 / 还原 | `Ctrl+B`（或 `Alt+'`） |
| 左右 / 上下拆分面板 | `Alt+[` / `Alt+]` |
| 新建标签页（复制当前） / 关闭标签页 | `Ctrl+T` / `Ctrl+W` |
| 切换到前一个 / 后一个标签页 | `Ctrl+Shift+Tab` / `Ctrl+Tab` |
| 后退 / 前进（导航历史） | `Alt+←` / `Alt+→` |
| 路径栏改为文本输入 | `Ctrl+L` |
| 把当前面板切换为：场景视图 / 网络编辑器 / 参数 / 树视图 | `Alt+1` / `Alt+2` / `Alt+3` / `Alt+4` |
| 切换为：几何表格 / 动画编辑器 / 材质面板 | `Alt+8` / `Alt+6` / `Alt+7` |
