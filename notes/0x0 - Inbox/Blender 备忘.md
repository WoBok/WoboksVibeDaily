## Blender 基础快捷键

MMB：旋转视角  
Shift + MMB：平移视角  
Scroll MMB：缩放视角  

~：视图导航菜单  
Shift + Space：工具切换菜单  

Shift + A：新建物体  
Shift + D：复制物体  
X / Delete：删除物体  
Ctrl + A：应用变换

H：隐藏选中物体  
Alt + H：显示所有隐藏物体  
Shift + H：隐藏未选中物体  

Tab：编辑模式
Ctrl + Tab：模式切换菜单  

Shift + C：Cursor 回到世界原点 + 显示整个场景  
Shift + S：吸附菜单

Z：渲染模式

## 概念
### Cursor

Blender 中一个可自由移动的**空间定位点 / 临时锚点**。

**三个概念的区别：**
- **World Origin（世界原点）**：固定的 `(0,0,0)`，整个世界的中心 → **地图零点**
- **Object Origin（物体原点）**：属于物体，决定物体自身的变换参考 → **物体轴心**
- **3D Cursor（3D 游标）**：可自由移动的临时参考点 → **空间图钉**

**主要作用：**
- 决定新物体生成位置
- 作为旋转、缩放的临时中心
- 精确定位、吸附物体
- 辅助设置 Object Origin

**常用操作：**
- `Shift + 右键` → 放置 Cursor
- `Shift + S → Cursor to Selected` → Cursor 移到选中位置
- `Shift + S → Selection to Cursor` → 选中物移到 Cursor
- `Shift + S → Cursor to World Origin` → Cursor 回到 `(0,0,0)`

**3D Cursor = 三维空间中可自由移动的临时定位锚点。**

### Blender 修改器核心指南

#### 核心概念

- **修改器**：按规则处理物体，但通常不直接改动原始网格，适合非破坏性建模。
- **修改器堆栈**：修改器按面板中**从上到下**的顺序执行；顺序不同，结果可能不同。
- **应用修改器**：把当前效果写入真实网格。应用后可直接编辑结果，但不能再调整原修改器参数。
- **原则**：设计未定时保留修改器；只有需要编辑生成的网格、导出或进入固定拓扑流程时再应用。

#### 基本操作

1. 对象模式下选中物体。
2. 打开属性编辑器中的**修改器（扳手图标）**。
3. 选择“添加修改器”。
4. 调整参数和堆栈顺序。
5. 必要时在对象模式按 `Ctrl + A`，应用“缩放”或“旋转与缩放”。

> 视口与渲染显示是独立开关；效果异常时先检查开关、堆栈顺序、物体原点、坐标轴和缩放。

#### 常用修改器

| 修改器 | 用途 |
| --- | --- |
| 镜像（Mirror） | 对称建模 |
| 阵列（Array） | 重复生成物体 |
| 倒角（Bevel） | 给边缘增加高光过渡 |
| 布尔（Boolean） | 相减开孔、相交或合并 |
| 实体化（Solidify） | 给平面增加厚度 |
| 细分曲面（Subdivision Surface） | 增加表面圆滑度 |

#### 示例一：阵列制作楼梯

1. 添加立方体，缩放成一级台阶。
2. 按 `Ctrl + A` →“缩放”。
3. 添加 **阵列（Array）** 修改器。
4. 将数量设为 `8`。
5. 关闭或调整“相对偏移”，开启“恒定偏移”。
6. 设置逐级向前、向上的偏移，例如：

   ```text
   X = 0
   Y = 0.35 m
   Z = 0.18 m
   ```

7. 若方向错误，调整轴向或数值正负。

#### 示例二：在墙上开洞

1. 添加立方体并缩放成墙体，按 `Ctrl + A` →“缩放”。
2. 再添加一个立方体，缩放成洞口，并让它 **完整穿过墙体** 。
3. 选中墙体，添加 **布尔（Boolean）** 修改器。
4. 运算选择“差集（Difference）”。
5. 将洞口立方体设为运算对象。
6. 隐藏洞口立方体，或把它改为线框显示。
7. 保留修改器即可继续调整洞口；确定不再修改时再应用。

推荐顺序：

```text
布尔 → 倒角 → 加权法线或平滑
```

#### 记住三点

1. 修改器从上到下执行。
2. 缩放、原点和坐标轴会影响结果。
3. 没有明确需要时，不要急着应用修改器。
