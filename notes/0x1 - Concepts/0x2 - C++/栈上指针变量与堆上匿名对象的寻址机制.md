```c
int *p = malloc(sizeof(int)); // 假设 *p = 99;
```

## 1. 指针变量与动态内存

| 比较维度 | 实体 A（栈上的指针变量） | 实体 B（堆上的动态内存） |
| --- | --- | --- |
| **存储区域** | 栈区（Stack） | 堆区（Heap） |
| **存储内容** | 目标内存地址（即堆对象的物理/虚拟地址） | 实际的业务数据（如 `99`） |
| **符号标识** | **具名实体**（源码中用符号 `p` 标识） | **匿名实体**（无任何语言符号） |
| **寻址机制** | 编译期通过符号表绑定（如栈偏移 `[rbp-8]`） | 运行时通过解引用存储于 `p` 的地址动态寻址 |

> **变量名 `p` 本质上仅是栈上那个指针变量的源码代号，它唯一的作用是帮编译器在栈上锚定一个指针变量的位置。** `p` 既不等于堆上的对象，也不等于堆上的地址；编译完成后 `p` 这一名字即被销毁，只留下栈偏移。堆上的内存块自始至终都是**匿名的**。

## 2. 内存寻址关系与表达式解析

结合以下典型代码，剖析指针变量与堆内存之间的操作表达：

```cpp
#include <iostream>
#include <cstdlib>

int main()
{
    int *p = (int*)malloc(sizeof(int) * 10); 
    if (p == nullptr) return 1;

    *p = 42;         // 等价于 p[0] = 42;
    *(p + 1) = 43;   // 等价于 p[1] = 43; 

    std::cout << "栈指针自身地址 (&p): " << &p << std::endl;
    std::cout << "堆首元素的值 (*p): " << *p << std::endl;
    std::cout << "堆内存首地址 (p): " << p << std::endl;
    std::cout << "堆内存首地址 (&(*p)): " << &(*p) << std::endl;

    free(p);
    p = nullptr;
    return 0;
}
```

* **堆上对象**：由 `malloc` 在堆区开辟的连续匿名内存块，用于存放实际业务数据（如 `42`、`43`）。
* **栈上指针 `p**`：栈区中分配的具名变量实体，用于存储堆内存的首地址。
* **`&p`（取指针地址）**：获取指针变量 `p` 自身在栈帧中的内存位置。
* **`p`（读取指针值）**：直接读取变量 `p` 内部存储的数据，即所指向堆内存的首地址。
* **`*p`（解引用读写）**：依据 `p` 中保存的地址，间接访问并读写堆内存起始处的元素数据。
* **`&(*p)`（取首元素地址）**：先解引用定位堆首元素实体，再获取该实体的内存地址；其计算结果在数值与类型上均与 `p` 完全等价。

## 3. 编译期符号绑定与运行时动态寻址

```c
int *p = malloc(sizeof(int));
*p = 99;
```

1. **编译期符号替换（名字彻底消除）**：
编译器查符号表确认 `p` 的类型与作用域，随后将代码中所有出现 `p` 的地方，**直接替换为具体的底层定位方式**（如栈偏移 `[rbp-8]` 或分配到寄存器）。此时机器指令中已无 `p` 这个符号。
2. **运行时地址写入**：
`malloc` 动态分配内存并返回堆地址（如 `0x2000`），CPU 执行指令将该地址值写入 `[rbp-8]`。
3. **间接寻址与赋值**：

* **第一步（读取指针值）**：从 `[rbp-8]` 处读取保存的堆地址 `0x2000`。
* **第二步（目标空间写入）**：向地址 `0x2000` 对应的堆内存单元写入数值 `99`。

堆上的内存单元不具备语言层面的标识符，仅作为一个由指针变量或寄存器在运行时指向的内存目标。

## 4. 核心要点

* **栈上指针变量**：源码中用标识符 `p` 标记，编译后即被硬编码为栈偏移或寄存器，其物理存储的内容是一个内存地址。
* **堆上动态对象**：无语言层面的标识符（匿名），生命周期由程序显式控制，必须依赖运行时地址进行间接访问。

---

> **`p` 自身是栈上的指针实体，`p` 存储的内容是堆的首地址，堆内存全程保持匿名并完全依赖该地址进行间接访问。**
