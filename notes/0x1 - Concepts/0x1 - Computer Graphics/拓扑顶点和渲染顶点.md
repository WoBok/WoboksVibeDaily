> 为什么Box模型8个顶点，导入到UE却成了24个顶点？
>

在 Maya 中看到的 8 个顶点是拓扑顶点，每个顶点可以被多个相邻面共享。

而在 Unreal Engine 中看到的 24 个顶点，是渲染顶点（GPU 顶点），GPU 顶点除了位置，还包含：

```plain
Position + Normal + Tangent + UV + Color ...
```

**同一拓扑顶点在相邻面上的法线、UV、切线等属性不一致时，UE 会将其拆成多个渲染顶点。**

 立方体为硬边时，每个拓扑顶点连接3个面，对应3个不同的面法线：

```plain
8 个拓扑顶点 × 3 个法线方向 = 24 个渲染顶点
```

按6个面计算：

```plain
6 个面 × 4 个顶点 = 24 个渲染顶点
```

在 Unreal Engine 里，软边只能合并法线（Normal），但如果UV 被切开（UV Seam），顶点仍然会被拆分。

所以Box：

```plain
8 个拓扑顶点
→ 因为 UV 拆分
→ 变成 14 个渲染顶点
```

---

GPU 判断是否是“同一个顶点”，看的是：

```plain
Position + Normal + UV ...
```

只要其中一个不同，就会拆点。
