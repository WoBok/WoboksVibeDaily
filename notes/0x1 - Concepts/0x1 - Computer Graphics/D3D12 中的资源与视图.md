## 基本概念

Resource 回答"数据是什么形态、放在哪里"（维度、尺寸、mip、格式族、所在堆），View 回答"这次把它当什么用"（取哪一段、按什么格式解释、以什么角色接入管线）。View 不复制数据。

- View 的实体是 Descriptor
- 同一个 Resource 可以创建多个兼容 View
- View 只描述如何访问，不保证访问正确：切换读写用途仍需处理 Resource State / Layout、Barrier 和同步
- Sampler 与 SRV 分离：SRV 描述读取什么，Sampler 描述如何采样

## 五种视图

| 视图 | 主要用途 | 特点与限制 |
|---|---|---|
| **RTV** | 光栅化的颜色输出 | 可混合；不能作为着色器随机访问接口 |
| **DSV** | 深度/模板测试与写入 | 可利用 Early-Z、Hi-Z、深度压缩；要求兼容的深度/模板格式 |
| **SRV** | 着色器只读访问 | 可用于纹理或 Buffer；纹理采样可用过滤和 mipmap |
| **UAV** | 着色器随机读写 | 支持原子操作；顺序与可见性需 Barrier 显式保证 |
| **CBV** | 着色器只读常量参数 | 单个 View 上限 64KB；适合线程间高度一致的频繁读取 |

## API 概念对照

> 以下只是概念对应，并非完全一一等价。

| D3D12 | Vulkan | Metal |
|---|---|---|
| RTV | color attachment | color attachment |
| DSV | depth/stencil attachment | depth/stencil attachment |
| SRV | sampled image / read-only buffer | texture / read-only buffer |
| UAV | storage image / storage buffer | read-write texture / buffer |
| CBV | uniform buffer | constant buffer |
