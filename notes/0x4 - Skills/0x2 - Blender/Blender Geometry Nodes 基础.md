## 1. 核心概念

几何节点是一个可自行搭建的**几何加工流水线**，也是修改器的一种。

```text
Group Input → 生成 / 选择 / 运算 / 变换 → Group Output
```

- `Group Input`：输入原始几何和可调参数；
- 中间节点：读取、生成、筛选或修改数据；
- `Group Output`：输出最终几何；
- 任一上游变化，整条节点链会重新计算。

## 2. 什么是 Geometry

Geometry 不是单个物体，而是一份可在节点间传递的**几何数据容器**。一个物体还包含名称、变换、层级等信息；Geometry 主要关心形状及其数据。

| 几何组件 | 内容 | 常见用途 |
| --- | --- | --- |
| Mesh（网格） | 顶点、边、面 | 常规建模 |
| Curve（曲线） | 样条与控制点 | 路径、绳索、藤蔓 |
| Point Cloud（点云） | 只有点及点属性 | 散布、粒子式效果 |
| Instances（实例） | 对其他几何的引用 | 大量复制物体 |
| Volume（体积） | 体素/网格数据 | 烟雾、体积造型 |
| Grease Pencil（蜡笔） | 笔画与图层 | 2D/3D 笔画处理，视版本而定 |

> 节点通常只处理指定组件。节点“没反应”时，先确认输入的几何类型是否匹配。

## 3. 属性、字段与域

### Attribute（属性）

属性是附着在几何元素上的数据，例如：

- `Position`：位置；
- `Normal`：法线；
- `ID / Index`：标识或索引；
- `UV / Color`：纹理坐标或颜色；
- 自定义的密度、遮罩、随机值等。

### Field（字段）

字段不是一个固定结果，而是一个**逐元素计算规则**。

```text
Position.Z > 0
```

意思是：对当前域中的每个元素，判断它的 Z 坐标是否大于 0。得到的布尔字段可连接到 `Selection`，只处理满足条件的部分。

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| 单值 | 所有元素共用一个值 | 所有实例缩放为 `0.5` |
| 字段 | 每个元素分别求值 | 每个点使用不同随机缩放 |

### Domain（域）

域决定属性存在哪类元素上，也决定字段“逐谁计算”。

| 几何 | 常见域 |
| --- | --- |
| Mesh | Point、Edge、Face、Face Corner |
| Curve | Control Point、Spline/Curve |
| Point Cloud | Point |
| Instances | Instance |

同一属性换到不同域，含义会改变。例如颜色在 Face 域是每面一个值，在 Point 域则可在顶点间插值。

## 4. Instance 与 Realize

| | Instance（实例） | Realize Instances（实体化） |
| --- | --- | --- |
| 本质 | 引用原几何 + 变换 | 展开为真实顶点、边、面 |
| 性能 | 省内存、适合大量复制 | 几何量可能快速增长 |
| 可做操作 | 整体平移、旋转、缩放 | 可逐点修改、布尔、合并等 |

**使用原则：能保持实例就保持实例；必须逐点处理时再实体化，并尽量放在节点链后段。**

## 5. Capture Attribute 与 Named Attribute

### Capture Attribute（捕获属性）

用途：把某一阶段的字段结果立即计算并附着到几何上，使它能跨过后续的拓扑或组件变化继续使用。

```text
原表面法线 → Capture Attribute → 撒点 / 转换几何 → 后段继续使用原法线
```

为什么需要捕获：后续几何改变后，再读取 `Normal`、`Position` 等字段，读到的是**新几何**的数据，不再是早期数据。捕获属性通常是匿名的，适合节点组内部临时传递。

### Named Attribute（命名属性）

用途：用明确名称保存和读取属性，适合：

- 几何节点与材质之间传值；
- 不同修改器之间传值；
- 应用修改器后仍需保留数据。

`Store Named Attribute` 负责写入，`Named Attribute` 负责按名称读取。名称区分大小写，写入类型和域应与用途一致。

| 需求 | 选择 |
| --- | --- |
| 节点组内部临时传递 | `Capture Attribute` |
| 给材质或其他修改器读取 | `Named Attribute` |

## 6. 基本操作逻辑

```text
Group Input → 确定范围 → 处理几何 → 整理结果 → Group Output
```

1. **输入**：确认是网格、曲线、点还是实例。
2. **范围**：确定计算域；需要局部处理时连接 `Selection`。
3. **处理**：按目标生成、变换、删除、散布或转换几何。
4. **属性**：几何改变前，按需使用 `Capture Attribute` 保留数据。
5. **实例**：优先保留实例；需要逐点编辑时再 `Realize Instances`。
6. **输出**：整理或合并结果，连接到 `Group Output` 并检查效果。

## 8. 案例

### 制作起伏地面上的碎石

1. 添加 **栅格（Grid）**，将 X、Y 细分设为 `50`。
2. 新建几何节点，在栅格后添加 **设置位置（Set Position）**。
3. 使用 **噪波纹理（Noise Texture）** 控制 Z 轴偏移，制作起伏地面。
4. 添加 **捕获属性（Capture Attribute）**，提前保存地面的法线。
5. 添加 **在面上分布点（Distribute Points on Faces）**，密度设为 `20`。
6. 添加 **二十面体（Ico Sphere）**，半径设为 `0.03`，细分设为 `1`。
7. 使用 **于点上实例化（Instance on Points）**，将二十面体分布到点上。
8. 添加浮点 **随机值（Random Value）**，范围设为 `0.3～1.5`，连接实例缩放。
9. 添加 **对齐旋转到矢量（Align Rotation to Vector）**，轴设为 Z，并连接捕获的法线，使碎石贴合坡度。
10. 使用 **噪波纹理 + 映射范围（Map Range）** 控制分布密度，形成自然疏密。
11. 将随机种子、缩放等暴露到修改器面板。
12. 需要修改顶点、进行布尔或导出网格时，再添加 **实体化实例（Realize Instances）**；其余情况保留实例以提高性能。
